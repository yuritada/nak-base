## 既知の問題・バグ

### 1. フロントエンドの履歴表示問題（優先度: 高）

- **症状:** `papers/[id]/page.tsx` でバージョン履歴が正しく表示されない
- **コミット:** 3a532db で「フロントエンドの履歴見れない問題はそのまま」と記載
- **原因の推測:** `getVersions(paperId)` のAPI応答と、フロントエンドでの `version.paper_id === paperId` の比較ロジックが、親子関係をまたぐバージョン表示で不整合を起こしている可能性
- **対応:** バックエンドの `GET /papers/{paper_id}/versions` のレスポンスとフロントエンドの表示ロジックをデバッグする必要あり

### 2. Ollamaコンテナが無効化されている

- `docker-compose.yml` で Ollama がコメントアウトされている
- `MOCK_MODE=true` のため、LLM推論はすべてダミー応答
- 本番利用にはOllamaの有効化とモデルのpullが必要

### 3. 未コミットの変更が4ファイルに存在

- 前回の作業途中で止まった変更が残っている
- まずこれらの変更内容を確認し、コミットするか破棄するか判断が必要

## システム構成（現状）

```
Frontend (Next.js 14)  :3000
    ↓
Backend  (FastAPI)     :8000  ← SSE通知も提供
    ↓               ↓
  DB (PostgreSQL+pgvector) :5432
  Redis              :6379  ← タスクキュー + Pub/Sub
    ↓
Worker (Python)            ← Redis BLPOPでタスク取得
    ↓
Parser (FastAPI)     :8001  ← PDF/TeX/DOCX/ZIP → 構造化テキスト
```

- Ollamaコンテナは現在無効（MOCK_MODE）
- Google Driveストレージコンテナは未実装
