あらまし 近年の⽣成 AI の進展により， Text-to-3D 技術は⾶躍的な視覚的品質を達成したが，既存⼿法はレンダリ ング画像の「⾃然さ」を優先するため，物理的・⼯学的整合性を⽋く問題（本稿では幾何学的ハルシネーションと定 義する）が未解決の課題となっている．本研究では，幾何学的ハルシネーションという課題に対し， Model Context Protocol (MCP) を基盤とした⾃律的品質保証フレームワークを提案する．提案⼿法は， LLM と 3D 環境（ Blender ） を接続し，視覚情報ではなく数値データ（座標，法線，⼨法）に基づいてモデルを直接検査・修正する「⽣成・検査・ 修正」サイクルを⾃律的に実⾏する．システムは，不変の「規制知識」と適応的な「経験知識」からなる⼆層知識構造 を有し，過去の修正プロセスから効率的な⽅策を獲得する知識継承メカニズムを備えている．建築制約を持つ⽣成タ スクにおける評価実験の結果，提案⼿法は視覚ベースでは困難な厳密な制約充⾜を達成した．さらに，性能推移の分 析により，知識の蓄積が⾃律性スコアを最⼤値の「 5 」まで向上させ，初期試⾏と⽐較してトークン消費量を約 58% 削 減することを定量的に実証した．提案するアプローチは， 3D ⽣成の評価軸を主観的な「⾒た⽬」から客観的な「構造 的整合性」へと拡張し，エンジニアリングツールとしての⽣成 AI の可能性を拓くものである．

近年，⽣成 AI 技術の進展は⽬覚ましく，テキストから画像， 映像，そして 3D モデルを⽣成することが⽇常的な技術となりつ つある．特に⼤規模⾔語モデル（ LLM ）を⽤いた「 3D-GPT 」 [1] のようなプロシージャル⽣成フレームワークは，専⾨的なスキ ルを持たないユーザでも複雑な 3D シーンを構築できる可能性 を切り開いた．しかし，既存の Text-to-3D 技術が⽣み出す成 果物は，レンダリング画像としての視覚的な「⾃然さ」におい て優れている⼀⽅で，構造的な「整合性」や物理的な「妥当性」 において致命的な⽋陥を抱えることが多い．

本稿では， ** 幾何学的ハルシネーション（ geometric hallucination ） ** とは，レンダリング画像上は⾃然に⾒えるにもかか わらず， 3D 空間内の幾何・物理・法規的制約（例：接地，⼲渉 回避，包含，⼨法整合，法規に基づく数値条件）を満たさない状 態を指すと定義する．本研究では特に，視覚的評価指標（例： 画像特徴に基づく類似度）だけでは検出が難しい「構造的違反」 を対象とし，以下のカテゴリに整理する．

[chunk 4 / page 1]
(i) 接地性違反 ：床⾯への⽀持がなく浮遊している．

(ii) ⼲渉（衝突）違反 ：オブジェクト同⼠が体積的に重なって いる．

(iii) 包含・埋没違反 ：壁や床に不適切に埋まる／外部へ突き抜 ける．

(iv) ⼨法・整列違反 ：垂直・⽔平，段差，クリアランス等が不 整合．

(v) 法規・設計数値違反 ：採光⾯積等，数値として定義可能な 設計条件を満たさない．

以上を「幾何学的ハルシネーション」として包括し，以降では 各カテゴリを数値判定可能な制約として実装する．

幾何学的ハルシネーションが⽣じる根源は，現在の⽣成パラ ダイムが CLIP スコア [2] や LPIPS[3] といった「視覚的評価」 に過度に依存している点にある． VLM は画像の類似性を判断 できても， 「垂直性」 「接地性」 「包含関係」といった 3D 空間特 有の厳密な幾何学的制約を， 2D 画像から正確に逆推論するこ とは本質的に困難である．

[chunk 5 / page 2]
本研究の⽬的は，建築制約を持つ屋内 3D シーン⽣成におい て，視覚情報に依存せず，数値データに基づく厳密な検査のみ を⽤いた⾃律的品質保証フレームワークを構築することである． 特に，静的な法規制を格納する StaticDB と，動的な経験知識 を蓄積する DynamicDB を分離・統合するアーキテクチャによ り，幾何学的整合性の保証と，試⾏回数の削減による推論コス トの最適化を同時に達成することを，定量的に実証する．

提案システムの特徴は，書き換え不可能な規制知識を扱う StaticDB と，ユーザからのフィードバックを通じて成⻑する経 験知識を扱う DynamicDB を分離した⼆層知識モデルにある． エージェントは，物理法則や建築基準法といった絶対的なルー ルを遵守しつつ，対話を通じて得た修正指⽰を新たなルールと して知識ベースに蓄積する．知識の永続化により，セッション ごとに記憶がリセットされる従来の LLM エージェントの限界 を克服し，使い込むほどに⽂脈理解が深化し，推論コストが最 適化される「経験を蓄積するパートナー」としての AI を実現 する．

本研究の主な貢献は以下の 2 点に集約される．本質的に，提 案⼿法は Text-to-3D という特定のドメインに留まらず， 「数値 的に検証可能な⽣成タスク⼀般」に対して適⽤可能な，普遍的 な品質保証原理を⽰唆している．

数値検査に基づく MCP ループの構築 : 視覚的評価を完 全に排除し， MCP を介して 3D 座標・法線データを直接 検証するループを実装した点．数値的な検証により，画像 ベースの⼿法では検出不可能なオクルージョン領域や微細 な位置ズレの修正を可能にした．

⼆層知識構造による探索の効率化 : エージェントの知識を 不変の「規制」と可変の「戦略」に分離し，修正プロセスで 得た成功パターンを永続化するメカニズムを実装した点． 経験の蓄積により，初期のランダムな探索から，知識検索 による即時解決へと⾏動を変容させることが可能となった．

[chunk 9 / page 2]
3D コンピュータビジョンとグラフィックスの分野は，深層学 習の導⼊により劇的な変⾰を遂げている．初期の 3D ⽣成モデ ルは，点群やボクセル，メッシュといった明⽰的な 3D 表現を 直接⽣成することを⽬的としており，初期の 3D ⽣成モデルの 評価には Chamfer Distance (CD) や Earth Mover's Distance (EMD) といった幾何学的距離指標が標準的に⽤いられてき た [5], [6] ．幾何学的距離指標は，⽣成された形状と正解データ との間の物理的な距離を測定するため，幾何学的な忠実度を保 証する上では⼀定の有効性を持つ．しかし， CD は点密度の不 均⼀性に鈍感である「不感領域」の問題を抱え， EMD は計算 コストが⾮常に⾼いという実⽤上の課題があった．

その後， Neural Radiance Fields (NeRF) [7] や 3D Gaussian Splatting (3DGS) [8] の登場により，パラダイムは「画像から の逆投影」による⽣成へとシフトした．⽣成パラダイムのシ フトに伴い，評価指標も PSNR ， SSIM ，そして LPIPS[3] や CLIP Score[2] といった画像空間での知覚的類似性指標が主流 となった．特に LPIPS は⼈間の知覚と⾼い相関を持つとされ るが，画像空間での知覚的類似性指標は本質的に「 2D の⾒た ⽬」を評価するものであり， 3D 構造としての整合性を保証し ない．

例えば，ある視点からは整合して⾒えるが，裏側が⽋損して いる，あるいは物体同⼠が物理的に不可能な交差をしていると いった問題（ 2D チーティング）は，画像ベースの指標では検 出困難である [9] ．建築やプロダクトデザインのようなエンジニ アリンググレードの整合性が求められる領域において，画像空 間での指標のみを追求する指標は不⼗分であり，構造的な「妥 当性」を担保する新たな枠組みが必要とされている．

[chunk 12 / page 2]
LLM の⾼い推論能⼒を活かし，エージェントとして 3D 空間を操作させる試みも始まっている．代表的な研究である SceneCraft [10] は， ユーザの⾃然⾔語指⽰を Blender の Python スクリプトに変換し， Python スクリプトの実⾏結果をレンダ リング画像として取得，マルチモーダル LLM (MLLM) で解析 することで修正ループを回す⼿法を提案した． SceneCraft によ るアプローチは，プログラマティックな操作により幾何学的構 造をある程度制御できる点で画期的である．

しかし， SceneCraft 等の既存⼿法は「視覚フィードバック」 に依存しているため， VLM の空間認識能⼒の限界に縛られる という課題がある．視覚情報は 3 次元情報の 2 次元への圧縮 （射影）であり，そこから完全な 3D 構造を復元・評価すること は逆問題として本質的な不安定さを孕んでいる．例えば， 「物 体が床から数ミリ浮いている」といった微細な誤差や， 「壁の内 部に配管が正しく通っているか」といったオクルージョンの検 証は， 2D 画像からは原理的に不可能に近い．

[chunk 13 / page 2]
したがって，正確な 3D モデリングを実現するためには，視 覚情報に頼らない，シーンデータ（頂点座標，法線ベクトル， バウンディングボックス等）への直接的なアクセスと，数値に 基づく論理的な検証が必要となる．

[chunk 14 / page 3]
Anthropic によって導⼊された MCP[4] は， AI モデルと外部 ツール間の通信を標準化するオープンプロトコルであり，エー ジェントシステムの実装に⾰新をもたらしている．従来の関 数呼び出しが単発の関数実⾏を⽬的としていたのに対し [11] ， MCP はクライアント・サーバ間のステートフルな接続を維持 し，リソースの購読やプロンプトのテンプレート化，そして何 より「 Sampling 」プリミティブによる双⽅向のインタラクショ ンをサポートしている点が MCP の特徴である．

「 Sampling 」機能は，サーバ側（ツール側）からクライアント （ LLM ）に対して，コンテキストを与えた上で次の⾏動を能動的 に問い合わせることを可能にする． Sampling 機能により，エー

ジェントは⾃⾝の⾏動結果（ツールの出⼒やエラーメッセージ） を受け取り，⾏動結果を評価して次の⾏動を決定する⾃律的な ループ（ ReAct サイクル [12] や⾃⼰修正ループ [13], [14] ）を， 標準化されたプロトコル上で堅牢に実装可能となる．

[chunk 15 / page 3]
既存の UnrealMCP[15] などの実装は，⾃然⾔語によるコマ ンド実⾏を可能にしたが，体系的な評価フレームワークや，失 敗から学ぶ⾃⼰改善ループまでは実装されていないのが現状で ある．

既存研究には， LLM による 3D ⽣成・編集や，視覚フィー ドバックを⽤いた反復的改善の枠組みが提案されている．⼀⽅ で， (a) 数値制約に基づく体系的な検査（ quality checking ） ， (b) 検査結果に基づく⾃動修正の反復（ self-correction loop ） ， (c) セッションを跨いで知識を永続化し効率を改善する仕組み （ knowledge inheritance ） を，統合的に扱う研究は依然とし て限定的である．本研究はこの統合に焦点を当て，幾何・法規 に由来する数値制約を扱う品質保証ループと，⼆層知識ベース による継承メカニズムを提案する．

提案システムの設計思想は， ⾼度な推論を⾏う AI コア （ LLM ） と，物理的なシミュレーションを⾏う 3D 環境（ Blender [16] ） を明確に分離し， AI コアと 3D 環境の間を標準化されたイン ターフェース（ MCP ）で調停することにある． MCP を⽤いた 疎結合な設計により，特定の LLM や 3D ソフトウェアに依存 しない拡張性と，各コンポーネントの独⽴した進化を担保して いる．

本システムの中⼼モジュールは， (i) ⽬的の分解と⼿順の構 築を⾏う推論・計画モジュール， (ii) ツール実⾏結果（数値ロ グ）を解釈して次の⾏動を更新する反省（ reflection ）モジュー ル， (iii) ルール検索・参照を⾏う知識参照モジュールから構成 される．これらは Model Context Protocol （ MCP ）を介して 3D 編集ツールに接続され，外部ツールから得られる数値情報 を根拠として⾏動を選択する．

推論エンジンには，ローカル環境で動作する Ollama を介し て gpt-oss:20b モデルが接続されており，プライバシーを確 保しつつ低遅延な推論を実現している．

[chunk 20 / page 4]
AI コアからの抽象的な指⽰を，具体的な計算処理や 3D 操作 に変換する中間層である． MCP ルーターはリクエストを受け 取り，適切なツールモジュールに振り分ける． MCP 統合層に は， 3D オブジェクトの⽣成・操作（ T1, T2 ） ，シーンの幾何学 的検証（ T3 ） ，そして経験知識の蓄積・検索（ T4 ）といった機 能が，標準化された MCP ツールとして実装されている．標準 化されたツールの実装により， LLM は下位層の複雑な API を 意識することなく，関数呼び出しの形式で環境に介⼊できる．

提案⼿法の最⼤の独⾃性は，エージェントが参照する知識 ベースを，性質の異なる⼆つのストレージに分離・統合した点 にある（図 1 ：知識層） ．

[chunk 22 / page 4]
建築基準法，物理法則，あるいはプロジェクト固有の仕様書 など，絶対に変更してはならない「ハード制約」を格納する 静的なデータベースである．例えば「階段の蹴上げは 23cm 以 下」 「ドアは床に接していなければならない」といったルールが JSON 形式で定義される．規制ルールは検査ツール（ T3 ）に よって厳格に適⽤され，違反があれば即座にエラーとして検出 される．規制知識層はシステムの「法令遵守」を担保する役割 を担う．

[chunk 46 / page 7]
本実験で観測された「知識統合に伴う⼀時的な停滞（ Exp 4 ） 」 は，エージェントが複数のルール間の競合に直⾯したことに起 因すると考えられる．例えば， 「採光⾯積の確保（窓を⼤きくす る） 」と「ドアとの⼲渉回避（窓を⼩さく・移動する） 」という相 反する制約が同時に課された際，初期の知識ベースにはそれら を調停するメタルールが存在しなかったため，エージェントは 優先順位の決定に計算リソースを浪費し，結果としてパフォー マンスが低下した．

しかし， Exp 6 以降の回復は，試⾏錯誤を通じて「⼲渉回避を 最優先しつつ，⾯積要件を満たす配置を⾒つける」という複合 的な解決戦略が新たにルール化されたことを⽰唆している．こ れは，断⽚的な知識が相互にリンクされ，より強固な知識ネッ トワークへと構造化された過程であると解釈でき，本システム が単なる知識の蓄積だけでなく，知識の洗練を⾏っていること を裏付けるものである．

[chunk 47 / page 8]
本実験ではルール数が最⼤ 18 件であったため，全ルールを

コンテキストに含めることが可能であったが，実運⽤において 知識ベースが数百・数千件の規模に増⼤した場合，検索および 推論のコストが新たな課題となる．ルール数の増加は， RAG における検索精度の低下や，プロンプト⻑の増⼤による応答遅 延を引き起こす可能性がある．

この課題に対しては，現在の単純なキーワード・ベクトル検 索に加え，タスクの⽂脈に応じて必要なルールのみを動的に ロードする「階層的なメモリ構造」や，頻出するルールセット を統合して圧縮する「知識の蒸留」メカニズムの導⼊が有効で あると考えられる．これらは，本システムを実社会の⼤規模な 設計⽀援に応⽤する上で，次に取り組むべき重要な⼯学的課題 である．

[chunk 48 / page 8]
提案⼿法の核⼼である「数値データに基づく厳密な検査と修 正」のループは， Text-to-3D における建築ドメインに限定され るものではない．例えば，室内における「家具の動線確保」や， ⼯場配管における「接続整合性の検証」 ，あるいは機械部品設計 における「公差チェック」など，幾何学的制約として定式化可 能なあらゆる⽣成タスクに対して適⽤可能である．

視覚的評価は対象の⾒た⽬やテクスチャに依存するためドメ インごとの再学習が必要となる場合が多いが，本⼿法は「座標 と⼨法」という普遍的な物理量に基づいているため，検査ルー ルを差し替えるだけで，多様なエンジニアリングタスクへ柔軟 に転⽤できる⾼い汎⽤性を有しているといえる．

[chunk 49 / page 8]
本研究では， 3D ⽣成における幾何学的ハルシネーションと いう課題に対し， MCP を⽤いた数値的介⼊と⼆層知識構造に よる解決策を提⽰した．提案システムは，視覚情報に依存せず， 幾何データに基づく厳密な検査により，建築基準を満たす CAD グレードのモデル⽣成を実現した．特筆すべきは，規制知識と 経験知識の統合により，絶対的なルールの順守と，過去の修正 事例に基づく適応的な効率化を両⽴させた点にある．実験デー タは，知識の永続化が，初期の適応停滞を乗り越え，最終的に ⾃律性の向上と推論コストの劇的な低減に寄与することを実証 した．

[chunk 50 / page 8]
今後の展望として，家具配置や設備配管といったドメインへ の拡張が挙げられる．これらは同様に数値的な制約充⾜問題と して定式化可能であり，本実験では建築シーンに限定したが， 家具配置や設備配管など、数値制約として定式化可能なタスク ⼀般に適⽤可能である．また，現在は Blender に限定されてい る MCP サーバを Unity や Unreal Engine へと展開し，より 多様なシミュレーション環境での検証を進める必要がある．た だし，本実験は単⼀シナリオでの検証に留まっているため，よ り多様なタスクでの検証が必要である．加えて，実運⽤におい て知識ベースの規模が数百・数千件に増⼤した場合の検索コス トや，ルール間の競合解消については，今後の課題である．提 案⼿法が⽰した「数値的リアリズム」の追求と知識継承モデル は，⽣成 AI を単なるクリエイティブツールから，信頼性が不

可⽋なエンジニアリングや製造の現場で活⽤可能な⾃律システ ムへと昇華させるための重要な基盤となるであろう．
