あらまし 近年の⽣成 AI の進展により， Text-to-3D 技術は⾶躍的な視覚的品質を達成したが，既存⼿法はレンダリン グ画像の⾃然さを優先するため，物理的・⼯学的整合性を⽋く問題（本稿では幾何学的ハルシネーションと定義する） が未解決の課題となっている．本研究では，幾何学的ハルシネーションという課題に対し， Model Context Protocol （ MCP ）を基盤とした⾃律的品質保証フレームワークを提案する．提案⼿法は，⼤規模⾔語モデル (LLM) と 3D 環境 （ Blender ）を接続し，視覚情報ではなく数値データ（座標，法線，⼨法）に基づいてモデルを直接検査・修正する⽣ 成・検査・修正サイクルを⾃律的に実⾏する．システムは，不変の規制知識と適応的な経験知識からなる⼆層知識構 造を有し，過去の修正プロセスから効率的な⽅策を獲得する知識継承メカニズムを備えている．建築制約を持つ⽣成 タスクにおける評価実験の結果，提案⼿法は視覚ベースでは困難な厳密な制約充⾜を達成した．さらに，性能推移の 分析により，知識の蓄積が⾃律性スコアを最⼤値の 5 まで向上させ，初期試⾏と⽐較してトークン消費量を約 58% 削 減することを定量的に実証した．提案するアプローチは， 3D ⽣成の評価軸を主観的な⾒た⽬から客観的な構造的整合 性へと拡張し，エンジニアリングツールとしての⽣成 AI の可能性を拓くものである．

近年，⽣成 AI 技術の進展は⽬覚ましく，テキストから画像， 映像，そして 3D モデルを⽣成することが⽇常的な技術となりつ つある．特に⼤規模⾔語モデル（ LLM ）を⽤いた 3D-GPT[1] や Infinigen [2] のようなプロシージャル⽣成フレームワークは， 専⾨的なスキルを持たないユーザでも複雑な 3D シーンを構築 できる可能性を切り開いた．しかし，既存の Text-to-3D 技術 が⽣み出す成果物は，レンダリング画像としての視覚的な⾃然 さにおいて優れている⼀⽅で，構造的な整合性や物理的な妥当 性において致命的な⽋陥を抱えることが多い．

本稿では , レンダリング画像上は⾃然だが ,3D 空間内の幾何・ 物理・法規的制約を満たさない状態を幾何学的ハルシネーショ ンと定義する．具体的には , 接地性 , ⼲渉回避 , 包含 , ⼨法整合 , および法規に基づく数値条件の不整合を対象とする．本研究で は特に，視覚的評価指標（例：画像特徴に基づく類似度）だけ では検出が難しい構造的違反を対象とし，以下のカテゴリに整 理する．

[chunk 4 / page 1]
(a) 接地性違反：床⾯への⽀持がなく浮遊している．

(b) ⼲渉 ( 衝突 ) 違反：オブジェクト同⼠が体積的に重なって いる．

(c) 包含・埋没違反：壁や床に不適切に埋まる・外部へ突き抜 ける．

(d) ⼨法・整列違反：垂直・⽔平，段差，クリアランス等が不 整合．

(e) 法規・設計数値違反：採光⾯積等，数値として定義可能な 設計条件を満たさない．

以上を幾何学的ハルシネーションとして包括し，以降では各カ テゴリを数値判定可能な制約として実装する．

幾何学的ハルシネーションが⽣じる根源は，現在の⽣成パラ ダイムが CLIP スコア [3] や LPIPS[4] といった視覚的評価に 過度に依存している点にある．視覚⾔語モデル (VLM) は画像 の類似性を判断できても，垂直性，接地性，包含関係といった 3D 空間特有の厳密な幾何学的制約を， 2D 画像から正確に逆推 論することは本質的に困難である．

[chunk 5 / page 1]
本研究の⽬的は，建築制約を持つ屋内 3D シーン⽣成におい て，視覚情報に依存せず，数値データに基づく厳密な検査のみ を⽤いた⾃律的品質保証フレームワークを構築することである． 特に，静的な法規制を格納する StaticDB と，動的な経験知識 を蓄積する DynamicDB を分離・統合するアーキテクチャによ り，幾何学的整合性の保証と，試⾏回数の削減による推論コス トの最適化を同時に達成することを定量的に実証する．

[chunk 6 / page 2]
⼈間は視覚情報のみから，物体の安定性や⽀持関係の破綻を ⼀定程度推定できることが知られている．また仮想環境におけ るもっともらしさの破れは，空間的没⼊感や体験品質に影響し うる．しかし，⼈間の主観評価は暗黙的・⽂脈依存であり，設 計要件として再利⽤可能な形で明⽰されにくい．そこで本研究

では，違和感の原因となりやすい⽀持・⼲渉・包含・⼨法整合 といった構造条件を， 3D 空間上の数値制約として形式化し，決 定論的に検査可能な品質保証へ接続する．

具体的には， Model Context Protocol （ MCP ） [5] を介して LLM を 3D モデリング環境（ Blender ）に直接接続し，エージェ ントが 3D 空間を座標や⼨法といった数値データとして認識・ 操作するアーキテクチャを構築する．

[chunk 7 / page 2]
提案システムの特徴は，書き換え不可能な規制知識を扱う StaticDB と，ユーザからのフィードバックを通じて成⻑する経 験知識を扱う DynamicDB を分離した⼆層知識モデルにある． エージェントは，物理法則や建築基準法といった絶対的なルー ルを遵守しつつ，対話を通じて得た修正指⽰を新たなルールと して知識ベースに蓄積する．知識の永続化により，セッション ごとに記憶がリセットされる従来の LLM エージェントの限界 を克服し，使い込むほどに⽂脈理解が深化し，推論コストが最 適化される経験を蓄積するパートナーとしての AI を実現する．

[chunk 8 / page 2]
本研究の主な貢献は以下の 2 点に集約される．本質的に，提 案⼿法は Text-to-3D という特定のドメインに留まらず，数値 的に検証可能な⽣成タスク⼀般に対して適⽤可能な，普遍的な 品質保証原理を⽰唆している．

数値検査に基づく MCP ループの構築 : 視覚的評価を完全 に排除し， MCP を介して 3D 座標・法線データを直接検証 するループを実装した点．数値的な検証により，画像ベー スの⼿法では検出不可能なオクルージョン領域や微細な位 置ズレの修正を可能にした．

⼆層知識構造による探索の効率化 : エージェントの知識を 不変の規制と可変の戦略に分離し，修正プロセスで得た成 功パターンを永続化するメカニズムを実装した点．経験の 蓄積により，初期のランダムな探索から，知識検索による 即時解決へと⾏動を変容させることが可能となった．

[chunk 9 / page 2]
3D コンピュータビジョンとグラフィックスの分野は，深層学 習の導⼊により劇的な変⾰を遂げている．初期の 3D ⽣成モデ ルは，点群やボクセル，メッシュといった明⽰的な 3D 表現を 直接⽣成することを⽬的としており，初期の 3D ⽣成モデルの 評価には Chamfer Distance (CD) や Earth Mover's Distance (EMD) といった幾何学的距離指標が標準的に⽤いられてき た [6], [7] ．幾何学的距離指標は，⽣成された形状と正解データ との間の物理的な距離を測定するため，幾何学的な忠実度を保 証する上では⼀定の有効性を持つ．しかし， CD は点密度の不 均⼀性に鈍感である不感領域の問題を抱え， EMD は計算コス トが⾮常に⾼いという実⽤上の課題があった．

その後， Neural Radiance Fields (NeRF) [8] や 3D Gaussian Splatting (3DGS) [9] の登場により，パラダイムは画像からの 逆投影による⽣成へとシフトした．⽣成パラダイムのシフトに

伴い，評価指標も PSNR ， SSIM ，そして LPIPS[4] や CLIP Score [3] といった画像空間での知覚的類似性指標が主流となっ た．特に LPIPS は⼈間の知覚と⾼い相関を持つとされるが， 画像空間での知覚的類似性指標は本質的に 2D の⾒た⽬を評価 するものであり， 3D 構造としての整合性を保証しない．

例えば，ある視点からは整合して⾒えるが，裏側が⽋損して いる，あるいは物体同⼠が物理的に不可能な交差をしていると いった問題は，画像ベースの指標では検出困難である [10] ．建 築やプロダクトデザインのようなエンジニアリンググレードの 整合性が求められる領域において，画像空間での指標のみを追 求する指標は不⼗分であり，構造的な妥当性を担保する新たな 枠組みが必要とされている．

[chunk 11 / page 2]
LLM の⾼い推論能⼒を活かし，エージェントとして 3D 空間を操作させる試みも始まっている．代表的な研究である SceneCraft [11] は， ユーザの⾃然⾔語指⽰を Blender の Python スクリプトに変換し， python スクリプトの実⾏結果をレンダ リング画像として取得， VLM で解析することで修正ループを 回す⼿法を提案した． SceneCraft によるアプローチは，プログ ラマティックな操作により幾何学的構造をある程度制御できる 点で画期的である．

しかし， SceneCraft 等の既存⼿法は視覚フィードバックに 依存しているため， VLM の空間認識能⼒の限界に縛られると いう課題がある．視覚情報は 3 次元情報の 2 次元への圧縮（射 影）であり，射影された画像から完全な 3D 構造を復元・評価 することは逆問題として本質的な不安定さを孕んでいる．例え ば，物体が床から数ミリ浮いているという微細な誤差や，壁の 内部に配管が正しく通っているかというオクルージョンの検証 は， 2D 画像からは原理的に不可能に近い．

[chunk 12 / page 2]
したがって，正確な 3D モデリングを実現するためには，視 覚情報に頼らない，シーンデータ（頂点座標，法線ベクトル， バウンディングボックス等）への直接的なアクセスと，数値に 基づく論理的な検証が必要となる．

Anthropic によって導⼊された MCP[5] は， AI モデルと外部 ツール間の通信を標準化するオープンプロトコルであり，エー ジェントシステムの実装に⾰新をもたらしている．従来の関 数呼び出しが単発の関数実⾏を⽬的としていたのに対し [12] ， MCP はクライアント・サーバ間のステートフルな接続を維持 し，リソースの購読やプロンプトのテンプレート化，そして何 より Sampling 機能による双⽅向のインタラクションをサポー トしている点が特徴である．

Sampling 機能は，サーバ側（ツール側）からクライアント （ LLM ）に対して，コンテキストを与えた上で次の⾏動を能動的 に問い合わせることを可能にする． Sampling 機能により，エー ジェントは⾃⾝の⾏動結果（ツールの出⼒やエラーメッセージ） を受け取り，⾏動結果を評価して次の⾏動を決定する⾃律的な ループ（ ReAct サイクル [13] や⾃⼰修正ループ [14], [15] ）を，

標準化されたプロトコル上で堅牢に実装可能となる．

既存研究には， LLM による 3D ⽣成・編集や，視覚フィー ドバックを⽤いた反復的改善の枠組みが提案されている．⼀⽅ で， (a) 数値制約に基づく体系的な検査， (b) 検査結果に基づく ⾃動修正の反復， (c) セッションを跨いで知識を永続化し効率 を改善する仕組みを，統合的に扱う研究は依然として限定的で ある．本研究は統合に焦点を当て，幾何・法規に由来する数値 制約を扱う品質保証ループと，⼆層知識ベースによる継承メカ ニズムを提案する．

エージェントがタスク実⾏プロセスを通じて獲得した，特定 の⽂脈における有効な戦略や過去の成功・失敗パターンを蓄積 する動的なデータベースである [20] ．経験知識はシステムの稼 働に伴って成⻑する知識であり，ソフト制約として機能する． プランナーは，未知の状況に直⾯した際， DynamicDB から類 似局⾯における成功事例を検索拡張⽣成 (RAG)[21] により検 索し，⾏動計画の指針とする．経験知識層はシステムの適応性 と戦略獲得能⼒を担保する．

規制知識と経験知識の⼆重構造により，エージェントは法的 には正しいが⽂脈的に不適切な解を回避しつつ，効率的に最適 解を探索することが可能となる．

提案⼿法の核⼼である数値データに基づく厳密な検査と修正 のループは， Text-to-3D における建築ドメインに限定されるも のではない．例えば，室内における家具の動線確保や，⼯場配 管における接続整合性の検証，あるいは機械部品設計における 公差チェックなど，幾何学的制約として定式化可能なあらゆる ⽣成タスクに対して適⽤可能である．

視覚的評価は対象の⾒た⽬やテクスチャに依存するためドメ インごとの再学習が必要となる場合が多いが，本⼿法は座標と ⼨法という普遍的な物理量に基づいているため，検査ルールを 差し替えるだけで，多様なエンジニアリングタスクへ柔軟に転 ⽤できる⾼い汎⽤性を有しているといえる．

[chunk 48 / page 8]
本実験はプライバシーとコストの観点からローカル環境の 20B モデルを採⽤したが，パフォーマンスは基礎モデルの推論 能⼒に依存する． Exp 4 における知識統合に伴う停滞は，同規 模モデルの処理能⼒の限界に起因する可能性が⾼く，⼤規模商 ⽤モデル（例： GPT-4o ）を⽤いればより早期に⾃律性スコアが 最⼤値へ収束すると推測される．しかし提案する⼆層知識構造 の最⼤の意義は，推論能⼒に限りのある⼩規模ローカル LLM であっても，経験知識の外部化と継承により，専⾨家レベルの 品質保証ループを完全⾃律で完遂可能な枠組みを⽰した点に ある．

[chunk 49 / page 8]
本研究では， 3D ⽣成における幾何学的ハルシネーションと いう課題に対し， MCP を⽤いた数値的介⼊と⼆層知識構造に よる解決策を提⽰した．提案システムは，視覚情報に依存せず， 幾何データに基づく厳密な検査により，建築基準を満たす CAD グレードのモデル⽣成を実現した．特筆すべきは，規制知識と 経験知識の統合により，絶対的なルールの順守と，過去の修正 事例に基づく適応的な効率化を両⽴させた点にある．実験デー タは，知識の永続化が，初期の適応停滞を乗り越え，最終的に ⾃律性の向上と推論コストの劇的な低減に寄与することを実証 した．

[chunk 50 / page 8]
今後の展望として，家具配置や設備配管といった他ドメイン への拡張が挙げられる．本実験では検証対象を建築シーンに 限定したが，家具配置や設備配管などの空間設計タスクも数 値的な制約充⾜問題として定式化可能であるため，提案⼿法 の枠組みは汎⽤的に適⽤できると考えられる．さらに，現在 は Blender に動作が限定されている MCP サーバを Unity や Unreal Engine といった別プラットフォームへ展開し，より多 様なシミュレーション環境での有⽤性を検証する必要がある． 知識ベースの⼤規模運⽤に伴う検索コスト増⼤への対応も，継 続的な検討事項である．提案⼿法が⽰した数値的リアリズムの 追求と知識継承モデルは，⽣成 AI を視覚的なクリエイティブ ツールから，信頼性が不可⽋なエンジニアリングや製造の現場 で活⽤可能な⾃律システムへと昇華させるための重要な基盤と なるであろう．
